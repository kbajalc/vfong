# Project History

## Origins

The repository was created by **Hong Jen Yee (PCMan)** — a Taiwanese open-source developer
best known as the author of PCManFM (the default file manager for LXDE), libfm, and a number
of core Linux desktop components. This project is unrelated to those efforts: it is the
software artifact of his 2016 NTU master's thesis, *"Detecting Life-Threatening Arrhythmia
with Machine Learning Algorithms"*, submitted to the Graduate Institute of Biomedical
Electronics and Bioinformatics, National Taiwan University, July 2016.

The true start of development is **20 February 2016** — commit `1e20073`, *"Initial import.
Generate python2 wrapper for wfdb with ctypesgen."* — almost four months before what
`master`'s grafted root appears to be. The master branch carries only the final ~50 commits;
the full pre-history of ~290 additional commits survives in eight older branches that are
still present on the remote.

Hong used branches as sequential development stages rather than parallel feature tracks:
each branch is a renamed continuation of the previous one, started with `git checkout -b`
when beginning a new phase of work. The result is a linear chain of milestones preserved
under descriptive names.

---

## Stage 1 — Initial import and Python 2 WFDB wrapper (20 Feb 2016)

**Root commit `1e20073`** — Two files: `wfdb.py` (2,277 lines, auto-generated by ctypesgen
from the WFDB C library headers) and `wfdb_test.py` (67 lines). The entire project starts
as a thin Python 2 wrapper around the PhysioNet WFDB C library, enough to read ECG signals
and annotations from disk. No ML code, no features — just raw signal access.

---

## Stage 2 — `kmeans` (20 Feb 2016, 2 commits)

A two-commit dead-end that never went anywhere: the initial import plus a single *"Kmeans
test"* commit. Hong was apparently experimenting with unsupervised clustering to understand
the ECG segment data before committing to a supervised approach. The branch was abandoned the
same day it was created.

---

## Stage 3 — `strict-label` (Feb–Apr 2016, 79 commits)

The main early development branch. Key work:

**Literature survey infrastructure** — `dblp/` tooling (`query_dblp.py`) to search and
download paper metadata from DBLP; used to build the citation database for the thesis.

**First features implemented** — PSR (phase-space reconstruction), VF Leak, TCSC
(threshold-crossing sample count), TCI (threshold-crossing intervals). These were the earliest
candidate features, all implemented in pure Python initially.

**ROC analysis** (`dcca74b`) — Added code to compute ROC curves using predicted
probabilities rather than hard class decisions, evaluating classifiers at multiple operating
points.

**Python 3 port** (`4a0486a`) — Migrated the codebase from Python 2 to Python 3 (string
handling, print statements, division semantics). The ctypesgen WFDB wrapper was abandoned
in favour of a proper Cython extension (`wfdb_reader.pyx`).

**TCSC bug fix** (`1f56158`) — Fixed incorrect threshold computation in the TCSC feature.
The branch name "strict-label" refers to the labelling policy: segments were tagged with
strict rhythm annotations from WFDB, rejecting any segment where the annotation was
ambiguous.

---

## Stage 4 — `cython` (Apr 2016, +9 commits over `strict-label`)

A focused optimisation sprint: Hong added `cdef` static type declarations to the Cython
extensions to eliminate Python object overhead in the inner loops.

- `ec8f49f` — Initial Cython integration: converted the main feature module to `.pyx`
- `22a688d` — Fixed a bug in the TCSC Tukey cosine window; simplified the Cython build
  using a `.pyxbld` file
- `34eea7c` — Separated preprocessing (`signal_processing.pyx`) from feature extraction
  (`vf_features.pyx`); added `ndarray[double, ndim=1]` type annotations throughout
- `7cde240`, `a4b9a9f` — Further type annotations on numpy array indexing for additional speedup

The net result was a substantially faster feature extraction pipeline, necessary to make
the 100-iteration cross-validation experiments tractable.

---

## Stage 5 — `fix_spec` (Apr 2016, +31 commits over `cython`)

Spectral feature implementation and the evaluation framework.

**New features**: MAV (mean absolute value, `3746c6a`), A2 (energy ratio around peak
frequency, `d70d07c`), FM (spectral centroid, `822684f`), Hilbert-PSR (phase-space from
Hilbert transform, `b47e31e`). This filled out the frequency and phase-space feature groups.

**TCSC Tukey window parameter** (`e7c234b`) — Corrected the half-cosine window parameter;
the previous value produced a distorted window shape.

**scipy.signal.tukey()** (`3746c6a`) — Replaced hand-written cosine window with the
standard scipy implementation.

**Moving average via np.convolve()** (`d101224`) — Replaced a slow pure-Python loop with a
vectorised convolution. Also fixed division-by-zero in spectral feature normalisation.

**Univariate testing framework** — Added `univariate_test.py` to evaluate each feature
independently (one-feature SVM), quantifying individual discriminative power before
combining all 27.

**Class weighting** (`a62c586`) — Added `class_weight='balanced'` support to handle the
NSR-dominated imbalanced dataset.

---

## Stage 6 — `fix_label` (Apr 2016, +17 commits over `fix_spec`)

Label quality and classifier infrastructure.

**MEA reimplementation** (`dcbab80`) — The Modified Exponential Algorithm feature
(peak-tracking exponential decay) was rewritten from scratch after the original produced
incorrect values.

**SPEC index bug** (`79616db`) — A wrong array index in the spectral feature caused
misaligned frequency bin lookups. Silent correctness error.

**Adaboost added** (`e260e77`) — Extended the classifier comparison suite.

**SVM class-weight tuning** (`ad5e83d`, `a60bc7b`) — Tried to optimise the per-class
penalty weights for SVM via cross-validated grid search, since `class_weight='balanced'`
was not always optimal.

**Labelling bug fix** (`7205267`) — Corrected the WFDB rhythm-annotation parsing that was
silently miscategorising some rhythm transitions as the wrong class.

---

## Stage 7 — `old-segmentation` (Apr–May 2016, +52 commits over `fix_label`)

Dataset expansion and the segmentation pipeline.

**edb and mghdb added** (`b0ff475`, `eb0fcba`) — Extended the dataset from mitdb/vfdb/cudb
to all five PhysioNet databases. mghdb required special handling: Lead II is channel 1 (not
0), and records are hardcoded rather than listed in a file.

**Artifact-free segment listing** (`eb0fcba`) — `vf_data.pyx` gained the ability to
enumerate only segments that pass the artifact check, which became the basis for the 84,027-
segment corpus.

**AHA test structure introduced** — First version of the three-class (shockable /
intermediate / non-shockable) evaluation appeared in this branch.

**Train/test scaling separated** (`352c68c`) — A critical correctness fix: scaler was
previously fit on the combined train+test pool (data leakage). Now fit only on training
data.

**On-the-fly label generation** (`9b0292c`) — Moved label assignment from feature
extraction time to classification time, making it easier to experiment with different
labelling rules.

**Branch name** — "old-segmentation" was the working name at this stage because the
segmentation logic (how to split a record into 8-second windows) was the main focus and was
later refactored in `old_aha`.

---

## Stage 8 — `old_aha` (May 2016, +50 commits over `old-segmentation`)

The deepest pre-thesis branch. Most of the infrastructure that survived into the thesis was
finalised here.

**OSEA QRS detector integrated** (`ca0d938`) — Added the EP Limited OSEA-20 open-source
QRS detector (`osea20-gcc/`) and a Cython wrapper (`qrs_detect.pyx`). This replaced an
earlier simpler detector and enabled the four QRS-derived features (RR interval mean/std/CV,
unknown-beat ratio, VPC ratio).

**ADC zero value** (`adbad80`) — `wfdb_reader.pyx` was extended to read the ADC zero offset
from WFDB record headers and subtract it before converting to millivolts. Without this, the
mV baseline was wrong for records that used a non-zero ADC offset.

**AHA classification simplified** (`f19a5a7`) — The AHA-compliant three-class scoring was
consolidated into the version that became the thesis evaluation methodology.

**mghdb lead fix** (`c1f3263`) — Explicitly select channel 1 (Lead II) for mghdb records;
earlier code defaulted to channel 0 which is the wrong lead for this database.

**Count features C1, C2, C3** (`de0ef57`) — Implemented the three count-based features
(now `Count1`, `Count2`, `Count3` at indices 13–15): samples in the 50–100 % amplitude
range, samples above mean, and samples within the mean ± mean-deviation band. This brought
the feature set to its final count of 27.

**Label correction file** — Added support for `corrections_s8.txt`, an external file that
overrides the WFDB annotations for 747 manually reviewed segments where the automatic
annotation was wrong.

**LZ optimisation attempts** — Several commits tried alternative LZ implementations before
the C rewrite in the next stage.

---

## Stage 9 — `master` (28 May – 12 July 2016, +50 commits over `old_aha`)

The grafted root commit `4945776` (*"Use gradient boosting … instead of XGBoost"*) is the
first commit visible in the cloned `master` — but it continues directly from `old_aha`'s
tip. The full pre-history is only accessible via the older branches.

This final stage covered:

**May 28** — Root dump: accumulated work published; XGBoost replaced with
`sklearn.GradientBoostingClassifier`. On the same day: QRS raw-signal bug fixed, first-beat
skip added, Pyro4 distributed cluster implemented.

**May 29–31** — Cluster bugs fixed (hostname, threading lock, variable ordering, slave
configuration sync). `max_recall` scorer added. Old files removed.

**June 1** — LZ complexity rewritten in C (`vf_features_native.c`) for ~10× speedup;
`C(n)=0` initialisation bug fixed. IMF LZ extended from modes 1 and 5 to all five modes
(completing the 27-feature set).

**June 2–4** — RFE (Recursive Feature Elimination) experiments: manual feature ranking by
`coef_`/`feature_importances_`, `merge_reports.py` for cluster output aggregation, filter-
type feature selection with predefined ranking.

**June 6** — TCI rewritten across seven commits: pulse-tracking algorithm, boundary-second
exclusion, reduced from 127 to 73 lines. Same day: AHA-compliant three-class CSV output
fields added (`AHA_Se[shockable]`, `AHA_Sp[non_shockable]`).

**June 11–13** — Critical feature scaling data-leakage bug fixed (switched to `MinMaxScaler`
fit on training fold only). `VFClassifier` class introduced. Accuracy added to CSV output.

**June 14–17** — Test-score propagation bug fixed (RFE feature mask not applied to test
fold). Statistics module refactored.

**July 12** — `demo_emd.py` added: visualises EMD intrinsic mode functions on a sample ECG
segment. Font size tweak. Last commit before thesis submission.

## Stage 10 — `new_imf` (May 2016, 3 commits, branched from `4945776`)

A short parallel experiment: tried a simpler arithmetic approach to IMF complexity
(`9abf31c` — *"Try to use simpler way to calculate IMF complexity"*) rather than the C
implementation. Two more commits fixed a bug in `feature_extraction.py` and re-added the
cluster argument passing. Not merged into `master`; the C implementation was retained.
