# A New Ventricular Fibrillation Detection Algorithm for Automated External Defibrillators

**Authors:** A. Amann, R. Tratnig, K. Unterkofler
**Conference:** Computers in Cardiology, 2005, 32:559–562
**DOI:** https://doi.org/10.1109/CIC.2005.1588162

---

## Abstract

A new VF detection algorithm (HILB) based on the Hilbert transform and phase-space analysis. Evaluated on BIH-MIT, CU, and AHA databases (~333,583 decisions). HILB outperforms all other investigated algorithms (TCI, VF-filter, SPEC, CPLX) achieving the best IROC = 95%.

---

## Algorithm — Hilbert Transform (HILB)

### Concept

From a real ECG signal x(t), a complex signal z(t) is generated:
$$z(t) = x(t) + ix_H(t)$$

where x_H(t) is the Hilbert transform:
$$x_H(t) = \frac{1}{\pi}\text{P.V.}\int_{-\infty}^{\infty}\frac{x(\tau)}{t-\tau}d\tau$$

Then z(t) = r(t)exp(iφ(t)). A 2D phase-space plot is generated: x-axis = x(t), y-axis = x_H(t).

### Key Observation

- **VF signals:** Phase-space plots fill the x-y plane irregularly → many boxes visited
- **SR signals:** Phase-space plots show circle-like structures concentrated in restricted region → few boxes visited

### Decision Metric

Grid: 40×40 boxes. Measure d:
$$d = \frac{\text{visited boxes}}{\text{number of all boxes}}$$

VF classified if d > d₀ = 0.15. Critical threshold parameter for ROC: d₀.

**Implementation notes:**
- ECG downsampled to 50 Hz (no relevant info above 30 Hz)
- Preprocessing: same filtering.m as [COMP55-2005.md] (MA order 5, HP 1 Hz, LP 30 Hz)
- Window length: 8 s, steps of 1 s (same as COMP55)
- Same preprocessing, same databases, same evaluation procedure as COMP55

## Conclusion

HILB clearly yields best IROC. For any given specificity, HILB yields far the best sensitivity and is also the fastest algorithm.

In AED applications, specificity is more important than sensitivity — delivering unnecessary shock can cause cardiac arrest. HILB provides the best balance.

## Notes

- d₀ = 0.15 was fixed; ROC obtained by varying d₀
- Approximately 333,583 total decisions (same as COMP55)
- Phase-space approach exploits the structured vs. chaotic nature of ECG in VF
- Preceded by PSR (time-delay phase space reconstruction, TIME-2007) by same authors
