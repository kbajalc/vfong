# Ventricular Tachycardia and Fibrillation Detection by a Sequential Hypothesis Testing Algorithm

**Authors:** Nitish V. Thakor, Yi-Sheng Zhu, Kong-Yan Pan
**Journal:** IEEE Transactions on Biomedical Engineering, 1990, 37(9):837–843
**DOI:** https://doi.org/10.1109/10.36839
**Note:** This is the original TCI (Threshold Crossing Intervals) algorithm paper.

---

## Abstract

An algorithm for detecting VF and VT by sequential hypothesis testing. The ECG is converted to a binary sequence by threshold comparison, a probability distribution of threshold crossing intervals (TCI) is constructed, and VF is discriminated from VT by sequential hypothesis testing. Testing on 85 VF and 85 VT cases: 97.64% VF and 97.65% VT episodes identified after 5 s; 100% identification of both after 7 s.

---

## Algorithm — TCI with Sequential Hypothesis Testing

### Step 1: Threshold Analysis

The ECG is digitized at 200 samples/s. Preprocessing:
- HP filter (removes baseline drift)
- LP filter (removes muscle noise)
- 60 Hz notch filter (powerline)

Threshold set at **20% of peak signal value** for each 1-second segment. Threshold is allowed to adapt every second (amplitude immunity from low-level noise).

Binary sequence generated from the signal: 1 above threshold, 0 below.

### Step 2: TCI Calculation

For each 1-second segment, threshold crossing intervals T₁, T₂, ... Tₙ are measured. The average TCI is computed per stage.

TCI formula:
$$\text{TCI} = \frac{1000}{(N-1) + t_2/(t_1+t_2) + t_3/(t_3+t_4)} \text{ [ms]}$$

where N, t₁, t₂, t₃, t₄ are defined from the binary timing pattern.

**Probability distributions:**
- VF: TCI ~ Gaussian(μ = 105 ms, σ = 6.5 ms)
- VT: TCI ~ Gaussian(μ = 220 ms, σ = 16.5 ms)
- Normal: TCI ~ Gaussian(μ = 650 ms, σ = 13.5 ms)

VF and VT overlap, requiring statistical discrimination (sequential hypothesis testing).

### Step 3: Sequential Hypothesis Testing (Wald's SPRT)

Hypotheses:
- H_VF: μ_VF = 105 ms, σ_VF = 6.5 ms
- H_VT: μ_VT = 220 ms, σ_VT = 16.5 ms

Log-likelihood ratio function:
$$F_m = m \cdot \ln\left(\frac{\sigma_{VF}}{\sigma_{VT}}\right) + \frac{1}{2\sigma_{VT}^2}\sum_{i=1}^m(T_i - \mu_{VT})^2 - \frac{1}{2\sigma_{VF}^2}\sum_{i=1}^m(T_i - \mu_{VF})^2$$

Decision thresholds Γ₁ = ln((1-β)/α) and Γ₂ = β/(1-α):
- If F_m ≥ Γ₁ → accept H_VT
- If F_m ≤ Γ₂ → accept H_VF
- If Γ₂ < F_m < Γ₁ → continue testing (collect next T value)

### Parameters

- α = probability of rejecting H_VF when it is true (false positive rate)
- β = probability of rejecting H_VT when it is true (false negative rate)
- Test repeated on successive 1-second segments until decision reached
- Decision typically reached in 7 or 8 seconds

## Data

- 85 VF records + 85 VT records (monomorphic and polymorphic)
- From patients evaluated for automatic cardioverter-defibrillator implantation
- Recorded from external chest lead + transcardiac signal + catheter in superior vena cava
- 4-channel FM recorder (TEAC R-61), digitized at 200 samples/s (Metrabyte Dash-8)
- **Note: same database used for both training (probability distributions) and testing** — no independent verification

## Discussion

- Sequential testing provides elegant tradeoff between detection time and accuracy
- Higher accuracy requires more time (larger α, β → faster but less accurate)
- Typical AED decision needed in ≤10 s → set α, β accordingly
- Parameters (μ_VF, σ_VF, μ_VT, σ_VT) obtained from prior population database → can be precomputed
- Only simple algebra needed per new T_i value
- Algorithm operates on binary sequences → can be implemented in hardware (comparators + timers)
- **Limitation:** Algorithm tested on the same database used for parameter estimation

## Notes on COMP55-2005 Re-evaluation

In Amann et al. 2005 [COMP55-2005], TCI was re-evaluated on complete MITDB/CUDB/AHADB without preselection. Results were much lower:
- Overall Sensitivity: 75.1%, Specificity: 84.4%, IROC: 82%
- Original paper's 97%+ reflects hand-picked episodes and same-database parameter fitting
- VF dominant frequency in standardized databases is 3–5 Hz (TCI was parameterized for 9.5 Hz VF)
