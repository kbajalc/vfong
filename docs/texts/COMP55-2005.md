# Reliability of Old and New Ventricular Fibrillation Detection Algorithms for Automated External Defibrillators

**Authors:** Anton Amann, Robert Tratnig, Karl Unterkofler
**Journal:** BioMedical Engineering OnLine, 2005, 4:60
**DOI:** https://doi.org/10.1186/1475-925X-4-60

---

## Abstract

10 VF detection algorithms (5 classical, 5 new) evaluated on complete MIT-BIH, CU, and AHA databases (~330,000 decisions per algorithm). Sensitivity, specificity, and area under ROC curve (IROC) reported. Values differ from earlier investigations due to no preselection of episodes. Best algorithm is a new one (SCA) presented here for the first time.

---

## Methods

- **Databases:** Complete BIH-MIT (48 files × 2 channels × 1805 s), complete CU (35 files × 1 channel × 508 s), AHA files 7001–8210 (40 files × 2 channels × 1800 s)
- **Preprocessing:** Moving average (order 5, removes HF noise); drift suppression (HP, 1 Hz); LP Butterworth (30 Hz)
- **Window:** 8 seconds, analyzed in steps of 1 second (**no preselection**)
- **Total decisions:** 2×48×(1805−7) + 35×(508−7) + 2×40×(1800−7) = **~333,583 per algorithm**
- **Quality parameters:** Sensitivity, Specificity, Positive Predictivity, Accuracy, IROC (AUC)
- Binary classification: VF vs. no VF (no VT differentiation, since annotations don't distinguish VF from VT)

## Algorithms

### Classical Algorithms

#### TCI (Thakor 1990) — Time domain
Threshold crossing intervals. 1-second segments, threshold = 20% of maximum. Sequential hypothesis testing to separate VT from VF. For 8-second episode: 6 consecutive TCI values computed. Final SR if diagnosed in ≥4 segments, else VF. Critical threshold parameter: TCI₀.

#### ACF₉₅/ACF₉₉ — Autocorrelation (Chen 1987)
Linear regression of ACF peaks. SR if VR ≥ F-statistic at 95% (or 99%) confidence. Critical threshold: VR₀ = 6.61 (16.3) at 95% (99%).

#### VF-filter (Kuo & Dillman 1978) — Frequency domain
Narrow band-stop filter at mean signal frequency. Since no QRS detection: only threshold l₀ = 0.625 applied (signal higher than 1/3 of last VF-filter detected QRS in previous segment → l₀ = 0.406; otherwise l₀ = 0.625). Critical threshold: l₀.

#### SPEC (Barro 1989) — Frequency domain
FFT + Hamming window. Four parameters: M (FSMN), A1, A2, A3.
VF if M ≤ M₀=1.55, A1 < A₁,₀=0.19, A2 ≥ A₂,₀=0.45, A3 ≤ A₃,₀=0.09. Critical threshold: A₂,₀.

#### CPLX (Zhang 1999) — Complexity
Binary string complexity measure. VF if C₀ < C ≤ C₁=0.426 → VT; C > C₁ → VF. SR if C < C₀=0.173. Critical threshold: C₀.

### New Algorithms

#### STE — Standard Exponential (this paper)
Counts crossings of exponential curve decreasing from signal maximum:
$$E_s(t) = M\exp\left(-\frac{|t-t_m|}{\tau}\right), \quad \tau = 3\text{ s}$$
Rate N = n/T (crossings per minute). VF if N > N₀=250 cpm; SR if N < N₁=180 cpm; else VT.

#### MEA — Modified Exponential Algorithm (this paper)
Lifts decreasing exponential at each relative maximum. τ = 0.2 s. N₀=230 cpm.

#### SCA — Signal Comparison Algorithm (this paper, best performer)
Compares ECG with 4 predefined reference signals (3 SR + 1 VF cosine-like). Calculates residuals in L¹ norm. Uses probability test for QRS peak detection. Complex multi-step algorithm; see Appendix B for details. Critical threshold: t_{j,0}.

#### WVL₁ — Wavelet-based Algorithm 1
Continuous Mexican-hat wavelet transform + Fourier transform. Like SPEC in frequency domain.

#### WVL₂ — Wavelet-based Algorithm 2 (hybrid)
First uses SPEC to check for VF. If SPEC says "no VF", applies discrete wavelet transform (Daubechies 8, scale 3) to search for QRS complexes. VF if 2–40 QRS complexes found AND FSMN < 2.5 AND A2 > 0.2.

## Key Findings

- **VF-filter and SPEC** have high specificity (essentially 100%) but low sensitivity (~18–29%)
- **SCA** achieves the best IROC = 92%, with 71% sensitivity at 98.5% specificity
- **TCI** shows good overall sensitivity (~75%) but moderate specificity (~84%)
- Performance significantly lower than reported in original publications (due to no preselection)
- **ACF** performs poorly (IROC = 49%) — essentially random
- For AED applications, **specificity is more important** than sensitivity (wrong defibrillation can cause cardiac arrest)

## Important Note on SPEC Thresholds

With original thresholds, SPEC achieves essentially 100% specificity but only ~29% sensitivity. The original paper used CCU recordings from a specific dataset; the peak VF frequency in standardized databases (3–5 Hz) is lower than assumed by the original algorithm (5–9 Hz). This creates a systematic mismatch.

## Preprocessing Pipeline (filtering.m)

Standard preprocessing used across all algorithms in this paper (available as MATLAB function):
1. Moving average filter (order 5) — removes high-frequency noise and interspersions
2. High-pass filter (1 Hz cutoff) — removes baseline drift
3. Low-pass Butterworth (30 Hz cutoff) — suppresses remaining high-frequency content

This pipeline is also used by TCSC [TCSC-2009.md] and HILB/PSR/TIME algorithms.
