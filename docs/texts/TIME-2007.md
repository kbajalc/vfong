# Detecting Ventricular Fibrillation by Time-Delay Methods

**Authors:** Anton Amann, Robert Tratnig, Karl Unterkofler
**Journal:** IEEE Transactions on Biomedical Engineering, 2007, 54(1):174–177
**DOI:** https://doi.org/10.1109/TBME.2006.880909
**PMID:** 17260872

---

## Abstract

A new VF detection algorithm (PSR — phase space reconstruction / time-delay method) evaluated on BIH-MIT, CU, and AHA databases (~333,583 decisions). PSR outperforms all other investigated algorithms including HILB.

---

## Algorithm — Phase Space Reconstruction (PSR)

### Concept

Based on time-delay embedding (Takens' theorem for phase space reconstruction). The ECG signal x(t) is plotted in a 2D phase-space diagram with time delay τ:
- x-axis: x(t)
- y-axis: x(t+τ), τ = 0.5 s

### Key Observation

- **VF:** Fills phase space uniformly → high density → many boxes visited
- **SR:** Concentrated, structured trajectory → few boxes visited

### Decision Metric

40×40 grid (spanning signal minimum to maximum):
$$d = \frac{\text{visited boxes}}{\text{number of all boxes}} = \frac{\text{visited boxes}}{1600}$$

VF classified if d > d₀ = 0.15. (d₀ is the critical threshold parameter for ROC.)

**Implementation:**
- Preprocessing: filtering.m (MA order 5, HP 1 Hz, LP 30 Hz Butterworth)
- Window length: 8 s, steps of 1 s
- Assign decision to endpoint of 8-s interval (real-time simulation)
- Databases: Complete BIH-MIT + CU + AHA files 7001–8210

## Discussion and Conclusion

- PSR yields best overall IROC among algorithms compared in this paper (before HILB was added)
- In frequency domain: VF-filter and SPEC have near-100% specificity but low sensitivity (~18–29%)
- SPEC and VF-filter operate better for specificity >90%
- PSR clearly best for overall ROC performance
- Time-delay method captures chaotic/structured nature of VF/SR in phase space

---

## Relationship to Other Algorithms

This PSR algorithm was presented as a precursor; HILB [HILB-2005.md] uses Hilbert transform phase space and achieves IROC=95 vs. PSR IROC=94. Both use the same evaluation framework (COMP55-2005).

The TCSC algorithm [TCSC-2009.md] reports PSR IROC=96% (slight discrepancy, possibly different AHA file subset).
