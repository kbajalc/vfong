# Comparison of Five Algorithms for the Detection of Ventricular Fibrillation from the Surface ECG

**Author:** Irena Jekova
**Journal:** Physiological Measurement, 2000, 21(4):429–439
**DOI:** https://doi.org/10.1088/0967-3334/21/4/301
**PMID:** 11110242

---

## Abstract

Performance of five previously published VF detection methods evaluated on standardized databases (AHA and MIT). Test signals: 71 × 8-s sinus rhythm episodes and 90 × 8-s VF episodes. All algorithms showed expected reduction in sensitivity/specificity compared to original publications. Results can serve as baseline for comparison of newly developed algorithms.

**Keywords:** Fibrillation detection, algorithm performance, surface ECG

---

## ECG Signals

- **AHA Database:** Files A8001–A8009
- **MIT cudb:** cu01–cu35 (Creighton University Ventricular Tachyarrhythmia Database)
- **MIT vfdb:** Files 418–430, 602, 605, 607, 609, 611, 612, 614, 615 (MIT-BIH Malignant VF Database)
- **Episode duration:** 8 seconds (most AEDs analyze ECG in 6–12 s intervals)
- **Preprocessing:** Notch filter (50 Hz), high-pass (1 Hz), 2nd-order Butterworth LP (30 Hz)
- **Total episodes:** 71 SR (11 AHA, 26 MIT-cudb, 34 MIT-vfdb) + 90 VF (17 AHA, 35 MIT-cudb, 38 MIT-vfdb)

### Selection Criteria

- SR episodes excluded: very low amplitude (<0.25 mV), paced beats, gross artefacts, transitions to abnormal rhythms
- SR episodes with heart rate >150 bpm excluded (to give TCI equal conditions, since TCI uses ≥400 ms → only classifies SR if <150 bpm)
- Only SR vs. VF binary classification (VT requires separate approach, not considered here)

## Five Algorithms

### 3.1 TCI — Threshold Crossing Intervals (Thakor et al. 1990)

Standard 1-second segments with adaptive threshold (20% of max). TCI formula:
$$\text{TCI} = \frac{1000}{(N-1) + t_2/(t_1+t_2) + t_3/(t_3+t_4)} \text{ [ms]}$$

For 8-s episodes: eight consecutive 1-s segments analyzed. Final SR/VF decision if same result in ≥5 segments; 4:4 = "undecided". If TCI ≥ 400 ms → SR; otherwise sequential hypothesis testing (VT vs. VF).

### 3.2 ACF — Autocorrelation Function (Chen et al. 1987)

Linear regression analysis of ACF peaks. m=7 peaks. Variance ratio:
$$VR = \frac{b}{[R/(m-2)]}$$

If VR ≥ F-statistic (k1=1, k2=m-2, 95% probability) → SR; otherwise VF.

### 3.3 VF-Filter — Kuo and Dillman 1978

Narrow band-stop filter applied at mean signal frequency. Mean period:
$$T = 2\pi \sum_{i=1}^{m}|V_i| \left(\sum_{i=1}^{m}|V_i - V_{i-1}|\right)^{-1}$$

VF-filter leakage:
$$\text{leakage} = \sum_{i=1}^{m}|V_i + V_{i-T/2}| \left[\sum_{i=1}^{m}(|V_i| + |V_{i-T/2}|)\right]^{-1}$$

Two amplitude thresholds applied. Since no QRS detection here: only higher threshold (0.625) used.

### 3.4 Spectrum Analysis — Barro et al. 1989

FFT with Hamming window. VF if: FSMN ≤ 1.55, A1 > 0.19, A2 ≥ 0.45, A3 ≤ 0.09.

**Note:** Original thresholds failed here (100% specificity but only 3% sensitivity), because VF peak frequency F ≈ 3.4 Hz on this data, while original SPEC was designed for F = 5–9 Hz range. Modified thresholds used: VF if FSMN ≤ 2.5, A2 ≥ 0.35, A3 ≤ 0.25 (A1 not used, did not improve results).

### 3.5 Complexity Measure (Zhang et al. 1999)

Converts ECG to 0–1 binary string. Complexity measure C(n):
$$C(n) = \frac{c(n)}{b(n)}, \quad b(n) = \frac{n}{\log_2 n}$$

VT and VF identified if C > 0.173.

## Discussion

### TCI
- 98% overall sensitivity with TCI threshold 400 ms
- Many VF episodes classified as VT (dominant frequency 3–5 Hz, while Thakor parameterized for 9.5 Hz)
- MIT cudb worst results (shortest files: 8 min → artefacts and branch blocks disproportionately affect results)
- Specificity improvable by adjusting TCI threshold, but at cost of sensitivity

### VF-Filter
- Best sensitivity/specificity combination overall (94%/91%)
- Used only higher threshold (0.625) since no QRS detection
- Achieved best results without QRS detection or amplitude measurement

### Spectrum Analysis
- With original thresholds: 100% specificity but only 3% sensitivity (F too low)
- With modified thresholds: 79%/93% — acceptable performance
- Low peak frequency F of evaluated VF (3.4 Hz) vs. original design (5–9 Hz) is the main issue

### ACF
- Too much irregularity in SR (ectopic beats, T-waves) → specificity only 32%
- Some VF virtually periodic → reduced sensitivity (78%)

---

## Conclusions

- Presenting algorithms with ECG from different sources causes expected performance reduction
- VF-filter achieved best overall balanced performance: **94% sensitivity, 91% specificity**
- Results can serve as baseline for further assessments (noise sensitivity, new algorithm comparison)
